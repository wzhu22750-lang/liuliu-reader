# 溜溜读书整合版 APK

本次整合使用原番茄器 APK 的 Android/Tauri 宿主和 Rust 下载引擎，将阅读器前端打包到 APK 的 assets。全部原有 `.so` 在构建时逐一比较 SHA-256，不修改引擎、签名算法或正文处理协议。独立应用 ID 为 `com.liuli.reader.integrated`，可与原番茄器和 Capacitor 阅读器共存，不覆盖它们的数据。

## 使用

安装项目根目录的 `溜溜读书-整合版.apk`。打开书架右上角「在线找书」，搜索并选书，选择章节范围后点击「下载并入库」。通过结构检查的 TXT 按原目录拆分，保存到本机书架后可以离线阅读。不需要电脑服务、ADB 或另装原番茄器。

下载页可以关闭，再次打开「在线找书」可查看待处理任务并重新读取结果。取消按钮调用原引擎的任务取消操作。「移除记录」仅移除阅读器的恢复记录。后台执行取决于 Android 进程存活；没有加入前台下载服务，不保证系统杀进程后仍持续下载。下载页面关闭后，阅读器仍会观察引擎任务，并保存已完成任务的结果和文件路径；原引擎重启清空任务列表后，可利用该记录读取已经完成的文件。尚未完成或没有保存到完成状态的任务被杀进程后，需要重新下载。

这是使用本机测试证书签名的安装包，最低 Android 7.0（API 24）。实际 CPU 架构以源 APK 为准，构建和本次模拟器使用 ARM64。正式商店发布及原引擎的分发许可不在本次个人整合验收范围内。

## 下载与正文检查

- 引擎目录与公开页面目录须逐项核对书籍 ID、章节 ID、标题及顺序。
- 原引擎目录缺少访问标记，因此额外读取公开页面，保留来源受限/付费标记。选定范围有受限章节时不创建任务。
- 下载写入本应用专属目录，每个任务单独建子目录，不覆盖原番茄器或用户的其他文件。
- 原生读取桥只读该专属目录下的 TXT，校验 canonical path、文件大小和 UTF-8，限制 64 MB。
- `partial`、缺失章节、引擎错误、缺标题、乱序、明显失败/试读标记及不足 100 字的普通章节均不自动入库。“版权信息”等固定附属信息标题允许非空短文，并在完成页提示。较短的合法正文也可能被拒绝，页面会显示具体原因。
- 结构校验和字数阈值不能证明所有未标记的截断正文都完整。不能把某个样本成功作为任意书籍完整可下载的保证。
- 验收样本与结果见下方；不将测试数据或失败占位文本写成真实正文。

## 构建

```sh
npm ci
npm run lint
npm test
npm run apk:integrated
```

要求 JDK 21、Android SDK 36/build-tools 36.0.0、apktool、Python 3。默认源 APK 为相邻 `番茄器/番茄器.apk`；可通过 `FANQIE_APK` 指定。默认使用 `~/.android/debug.keystore` 的标准测试证书；可用 `LIULI_KEYSTORE` 选择相同别名与密码约定的测试证书。脚本在新建临时目录解包、补入文件桥、打包、16 KB 对齐与签名，最终只将已验签 APK 复制到项目目录。

交付包将 Android debuggable 和 WebView 调试调用参数设为 false；QA 构建可使用 `DEBUG_WEBVIEW=1`。当前 userdebug 模拟器（`ro.debuggable=1`）仍可发现 WebView 调试端口，普通实体手机上的最终行为尚未验证，不能据此声称所有设备均无法调试。

脚本按当前源 APK 中的明确 patch 点工作；源 APK 更新导致 patch 点变化时直接失败，避免生成缺失接线的 APK。

## 代码位置

- `src/platform/integratedFanqie.ts`：引擎调用、公开目录交叉校验、下载任务与恢复记录。
- `src/parsers/nativeExport.ts`：TXT 结构检查及按准确目录拆分。
- `native/integrated/LiuliReaderBridge.java`：下载目录、受限文件读取和异步公开目录请求。
- `scripts/build-integrated-apk.sh`、`scripts/patch-integrated-apk.py`：可复现整合与签名。
- 原有 Capacitor 构建与电脑端 Vite/ADB 桥接保留。
