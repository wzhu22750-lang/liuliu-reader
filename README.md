# 小说阅读器 · Reader AI

**Reader AI** 是一款面向小说阅读场景打造的**极简、无广告、本地优先的智能阅读器**。

项目以“**阅读 + 摘抄 + 高亮 + AI 语境理解**”为核心，将传统小说阅读与 AI 能力结合，让用户不仅能够舒适地阅读小说，还可以随时保存喜欢的内容、整理个人摘抄，并借助 AI 理解人物、剧情、设定和上下文。

### 核心功能

* 📚 **个人书库**：统一管理本地导入和在线导入的小说
* 📖 **沉浸式阅读**：简洁的阅读界面，支持章节、进度及阅读设置
* 📥 **小说导入**：支持 TXT、EPUB 等本地格式，并逐步扩展在线小说导入能力
* 🔗 **链接解析**：通过小说链接快速获取书籍信息、章节目录和正文内容
* ✨ **高亮与摘抄**：阅读过程中随时保存重要段落，建立个人摘抄库
* 📝 **笔记整理**：围绕摘抄添加个人理解与备注
* 🤖 **AI 语境理解**：结合当前章节和上下文，对人物、剧情、设定等内容进行智能分析
* 💾 **本地优先**：阅读数据、进度、摘抄等内容优先保存在本地，减少对云端服务的依赖

### 项目理念

Reader AI 不只是一个“打开小说然后阅读”的工具，而是希望建立一个属于用户自己的**小说阅读与知识沉淀空间**。

从：

> **发现一本书 → 导入 → 阅读 → 摘抄 → 思考 → AI 理解 → 沉淀**

形成完整的阅读闭环。

项目采用模块化设计，将**小说来源解析、内容获取、下载、本地书库、阅读器和 AI 能力**进行解耦，使未来可以在不改变核心阅读体验的情况下持续增加新的小说来源和功能。

**Reader AI —— 让阅读不止于阅读。**
